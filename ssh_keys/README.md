# ssh_keys ディレクトリ

SSHポートフォワード（踏み台サーバー経由接続）に使用する秘密鍵を配置するディレクトリです。

---

## サンプル DB 用デモ鍵（`test_key`）

`test_key` はリポジトリ同梱のサンプル DB コンテナ専用のデモ用鍵ペアです。
`docker compose up -d --build` 後、追加設定なしで SSH トンネル経由の接続を試せます。

- **秘密鍵**: `ssh_keys/test_key`（このディレクトリ）
- **公開鍵**: `ssh_server/authorized_keys`（SSH サーバーコンテナに組み込み済み）

> この鍵はローカルの Docker コンテナ専用のデモ鍵です。
> 実際のサーバーには使用しないでください。

---

## 実環境（本番サーバーへの SSH トンネル）での使用

実際のサーバーに接続する場合は、既存の秘密鍵をこのディレクトリにコピーしてください。

```bash
cp ~/.ssh/your_key ssh_keys/your_key
```

DB 接続設定画面の「SSH 鍵ファイルパス」に `/ssh_keys/your_key` を入力します。

> ⚠️ `test_key` 以外のファイルは `.gitignore` により Git 管理対象外です。
> 実際の秘密鍵をコミットしないよう注意してください。
